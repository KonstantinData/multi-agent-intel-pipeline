# Golden Test Artifacts

Dieses Verzeichnis enthält stabile Referenzartefakte für Architektur- und Integrationsregressionen.

## Struktur

- `runs/<baseline_run_id>/` enthält repräsentative Laufzeitartefakte.
- `quality_reference/` enthält kleinere Referenzdateien für Klassifikation/Lifecycle.

## Pflege

Golden-Dateien nur ändern, wenn sich das gewünschte Verhalten absichtlich geändert hat.
