# Security Policy

## Supported Versions

Only the actively maintained default branch (`main`) is supported for security fixes.

| Version/Branch | Supported |
| --- | --- |
| `main` | ✅ |
| older branches/tags | ❌ |

## Reporting a Vulnerability

Do not report vulnerabilities via public issues or pull requests.

Preferred reporting path:
1. Use GitHub private vulnerability reporting in the repository Security tab.
2. If private reporting is unavailable, contact the maintainers directly and include "SECURITY" in the subject.

Please include:
- affected commit SHA or tag
- impact and attack scenario
- minimal reproduction steps or proof of concept
- suggested remediation (if available)

## Response Targets

- initial triage response: within 48 hours
- status update cadence: at least every 7 days until closure
- coordinated disclosure: after fix availability or agreed embargo end
