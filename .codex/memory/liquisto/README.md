# Liquisto Memory Namespace

This namespace is dedicated to repository-specific process learning.

## Files

- `procedural_patterns.jsonl`: proven execution patterns.
- `anti_patterns.jsonl`: failure modes and avoid rules.
- `decision_policies.jsonl`: explicit routing and decision heuristics.
- `retrieval_index.json`: tags and ranking hints for top-k retrieval.
- `consolidation_reports/`: periodic merge/prune reports.
- `snapshots/`: versioned memory snapshots for rollback/audit.
